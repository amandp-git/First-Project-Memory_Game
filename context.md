# Repo Context

## What this project does
This repository contains a small browser-based Memory (Concentration) card game. The app is implemented in plain HTML, CSS, and JavaScript and runs directly in a web browser.

It lets users:
- play a classic matching-pairs game
- choose between 4x4 and 6x6 board sizes
- track moves, time, and star rating
- save best scores in browser local storage
- use keyboard navigation for accessibility
- play on desktop and mobile layouts

The main entry point is [memory-game.html](./memory-game.html), and the project is described in [README.md](./README.md).
